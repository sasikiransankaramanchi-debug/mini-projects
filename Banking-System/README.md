# Banking System

A simple Banking System developed using Python. This project demonstrates basic banking operations using Object-Oriented Programming (OOP) concepts.

## Features

- Create a bank account
- Display account details
- Deposit money
- Withdraw money
- Check account balance
- Handle insufficient balance during withdrawal

## Technologies Used

- Python

## Concepts Used

- Classes and Objects
- Constructor (`__init__`)
- Methods
- Instance Variables
- Conditional Statements
- User Input
- Basic OOP Concepts

## How It Works

The program creates a bank account using an `Account` class. Each account contains details such as:

- Account Number
- Account Holder Name
- Account Balance

The user can perform different banking operations such as depositing money, withdrawing money, and viewing account details.

## How to Run

1. Make sure Python is installed on your computer.
2. Open the project folder in VS Code or terminal.
3. Run the Python file:

python banking.py
