# SQL Mini Projects

## Overview
This folder contains SQL mini projects developed to practice database management, data querying, and data analysis using MySQL.

## Projects

### 1. Student Performance Analysis
A SQL-based project that analyzes student marks, department performance, and academic results using a sample student dataset.

**Analysis Performed:**
- Retrieve and filter student records
- Sort students by marks
- Calculate highest, lowest, and average marks
- Count students in each department
- Compare average marks across departments
- Assign grades using CASE statements
- Find the highest and second-highest marks
- Identify students performing above average
- Calculate pass and fail counts

**Concepts Used:**
- SELECT, WHERE, ORDER BY, DISTINCT
- Aggregate functions: COUNT, MAX, MIN, AVG
- GROUP BY and HAVING
- CASE statements
- Subqueries

## Technologies Used
- MySQL
- MySQL Workbench

## Learning Objectives
- Practice SQL queries from beginner to advanced levels
- Understand data aggregation and filtering
- Analyze structured data and generate useful insights
- Build a portfolio of database and data analysis projects
