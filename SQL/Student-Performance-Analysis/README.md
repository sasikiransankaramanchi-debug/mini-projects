# Student Performance Analysis

## Overview
A beginner SQL mini project that analyzes student marks, departments, and academic performance using MySQL.

## Tools Used
- MySQL
- MySQL Workbench

## Files
- `schema.sql` — Creates the database and table.
- `insert_data.sql` — Inserts sample student records.
- `analysis_queries.sql` — Contains SQL queries for data analysis.

## Analysis
This project uses filtering, sorting, aggregate functions, GROUP BY, HAVING, CASE statements, and subqueries.
