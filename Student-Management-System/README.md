# Student Management System

A basic Student Management System developed using Python. This project allows users to add student details, view students, search for a student, and calculate average marks.

## Features

* Add student details
* View all students
* Search for a student using Student ID
* Calculate average marks
* Exit the application

## Python Concepts Used

* Variables
* Data types
* Lists
* Dictionaries
* Functions
* If/elif/else statements
* For and while loops
* User input
* Basic calculations

## Technologies Used

* Python

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `student_management.py`.
4. Run the Python program.
